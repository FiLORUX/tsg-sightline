# Public viewer / owner editor

## Routes and authentication
Public projects use /view/*, without login. Access protects /context/admin/*; the old /context/* routes can remain protected but the origin allows only owner GET. Configure an Access policy for exactly david@thast.se and verify the actual configured issuer/audience. Every admin request independently validates signed JWT and exact email. The UI provides a custom Sightline sign-in dialog, and real credential entry stays with Cloudflare. Use docs/access-login.html for a paid Zero Trust custom login page, otherwise application branding and the built-in auth box. A failed or expired owner session never destroys a local draft.

## URL and publication
New links use #project=<random 128-bit hexadecimal ID>. There is no directory or list API. The ID is generated by cryptographically secure randomness, not a predictable production-name hash. A public link is not a confidentiality boundary. Rendered public imagery and GLB derivatives can be copied. The R2 bucket stays private. Keep raw CAD (DWG/DXF/SKP), original meshes, internal notes, schedules and source metadata outside all public routes.

The current R2 object projects/<id>/latest.json has metadata visibility=public and assets=<JSON array of derivative names>. Its body has publication=public-view/1 and is projected through an allowlist on every read and save. Source drawing and coordinate frame remain under controlled publication. Approved PNG/JPEG/WebP or GLB derivatives are content-addressed at projects/<id>/assets/<hash>.<ext>, with publicDerivative=1 metadata. No original formats are accepted. GLB must be an explicitly approved derivative. Manifest/admin responses are non-cacheable; public approved derivatives can be cached. Purge derivative caches on unpublication; public copies cannot be recalled.

Legacy #plan= links resolve by SHA-256 of the exact fragment via /view/alias/<digest>.json; R2 context/<digest>.json contains projectId metadata. Preserve the original fragment; it resolves the current pointer. A known alias with unavailable current data never falls back to an old revision. An unregistered portable link shows a warned position study. HTTP 308 cannot inspect fragments; keep canonical redirects and client alias resolution.

## Editing and local creation
Only owner may PUT /context/admin/project/<id>.json. Public GET always reports viewer. If-Match and R2 conditional writes prevent stale overwrites; Save updates camera and optical/rig information, paths, dimensions, sheet, not source frame/assets. Server assigns monotonically increasing sequence. Durable Object WebSockets send invalidations; conditional polling and focus refresh are fallback. Preserve selection and view when coordinate frame is unchanged. Conflicting local drafts are retained.

Visitors may create/edit/save local projects. Make local copy detaches from live state. Save local does not publish. Publish & save requires public-release consent, Turnstile, creates a fresh random project (never a client-provided ID), downloads the full local project with its publication URL and returns the link. Anonymous upload accepts the public plot schema and rendered PNG derivative (max 4 MiB, max 4096 per dimension); no raw CAD, arbitrary attachments or anonymous GLB upload. Grid-only studies are supported. Configure SIGHTLINE_TURNSTILE_SITEKEY and secret SIGHTLINE_TURNSTILE_SECRET. Server validates hostname and action. Creation fails closed if not configured; ordinary local Save still works. Configure account-level abuse monitoring, rate limits and owner operational removal; the per-location rate-limit binding is not a global cost cap.

## Deploy existing Singapore artifacts
Use the deploy session's current R04 package. Confirm raster and any derived GLB are approved for public release; never publish the old private manifest or original CAD. Choose a random project ID once and retain it:

    node tools/build-live-project.mjs <project.json> <private-output> --public-approved --project <id> --sequence <n> --revision R04 <legacy-link-or-digest>

Optional --glb <approved-derived.glb> only when actual registered visualisation exists. Supply --geometry-scope partial for a deliberately simplified or incomplete model, complete only if the derivative is known to represent the intended source model, or unknown if completeness has not been established. A complete label is not an engineering approval or a guarantee that the real venue is represented. Do not put private source details into public metadata. Upload assets first with publication.json derivativeMetadata, then CAS latest.json with publicationMetadata. Install legacy alias metadata projectId=<id> after the current pointer is available. Existing links stay unchanged. Future source revisions CAS the same pointer with increasing sequence and notify Durable Object or rely on polling. Keep original files private.

Deploy origin and canonical proxy together. Configure Access for /sightline/context/admin/* and exact owner; allow anonymous /sightline/view/*. Preserve signed assertion forwarding to admin and HTTP 101. Proxy CSP permits Turnstile only on Sightline app page. Preserve no-store for manifest/admin/alias/create, public-only derivative cache headers. Verify rate-limit namespace uniqueness, set production Turnstile keys, apply custom Access login template if plan supports it. No private source assets in GitHub.

Acceptance: anonymous old Singapore link opens actual R04; non-owner PUT fails, exact owner can save; two anonymous viewers update; local and cloud creation work with distinct opaque IDs; no original CAD or private metadata returned; latest actual raster/scale/counts/coverage; iOS pinch; geometry lazy loading. CI tests do not verify actual production artifacts or live Cloudflare configuration.
